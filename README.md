# EduTHCS static demo

EduTHCS is a static HTML, CSS, and JavaScript demo that can be hosted on GitHub Pages.

## Run locally

Open `index.html` in a browser or serve this directory with any static file server.

## Demo limitations

- There is no backend. Registration, sign-in, and learning data are stored only in the current browser's `localStorage`.
- Passwords are stored in browser storage and are not protected like credentials in a production authentication system. Use fictional details and a password you do not use anywhere else.
- Password recovery and third-party sign-in are unavailable because no verification or identity provider is configured.
- The admin and account pages are interface demos, not secure access-controlled services.
